# omp-operator

Kubernetes operator that runs [omp](https://github.com/can1357/oh-my-pi) (oh-my-pi) agents on
webhooks and schedules.

Status: under construction toward v0.1.0.

## Development

Tools are pinned in `mise.toml`; run `mise tasks` for the verbs (`mise run ci`, `mise run test-e2e`).
